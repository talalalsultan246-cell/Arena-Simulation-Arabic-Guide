# **دليل Excel QM وPOM-QM for Windows — من التثبيت إلى حل المسألة**

**إعداد:** Talal bin Ibrahim Alsultan  
**تحديث الدليل:** 27 أكتوبر 2026

إذا كنت تدرس بحوث العمليات أو النماذج الكمية في اتخاذ القرار، فغالبًا ستحتاج إلى أداة تساعدك على إدخال أرقام المسألة ومراجعة الحل دون كتابة جميع المعادلات يدويًا. في هذا الدليل أشرح **Excel QM**، ثم **POM-QM / QM for Windows**، وأربط استخدامهما بالموضوعات التي ظهرت في ملفات مادة *Quantitative Analysis for Management*. وفي النهاية ستطبق مسألة واحدة في المخزون للتأكد من فهم طريقة الاستخدام.

> **قبل أن تبدأ:** **Excel QM** إضافة داخل **Microsoft Excel**، أما **POM-QM for Windows** فهو برنامج مستقل. قد تشاهد اسمه **QM for Windows** حسب إعدادات المقرر؛ فلا تخلط بين ملف الإضافة وملف تثبيت البرنامج المستقل.

## الجزء الأول: التحميل والتثبيت

### 1. تحديد الإصدار المناسب

لديك مصدران مهمان: دليل المقرر الذي رفعته بعنوان **POM-QM for Windows — Version 5** (Howard J. Weiss، 2018)، وصفحة Pearson الخاصة بمواد كتاب **Quantitative Analysis for Management**. وهذه نقطة مهمة لأن بعض صفحات Pearson القديمة توفر **Excel OM/QM 5.3** و**POM/QM for Windows 4**؛ بينما ملف المقرر يشرح **POM-QM for Windows 5**. **لا تعتبر أن هذه الأرقام تمثل الإصدار نفسه.**

- [كتاب Quantitative Analysis for Management، الطبعة 14 — Pearson](https://www.pearson.com/en-us/subject-catalog/p/quantitative-analysis-for-management/P200000009863/9780137864966)؛ تضم ملحقاته قسمًا لاستخدام POM-QM وقسمًا مستقلًا لإضافة Excel QM.
- [موارد Pearson الخاصة بالطبعة 13](https://media.pearsoncmg.com/ph/bp/bridgepages/bp_render_bridgepage/qam_13e/index.html)؛ قد تظهر فيها ملفات Excel OM/QM وPOM-QM لإصدارات سابقة.
- رابط مواد الطبعة 14 كما يظهر في مصدر الكتاب: [Companion Website](https://media.pearsoncmg.com/intl/ge/2023/cws/ge_render_qam_14/cw/login/sign-in.php). قد يحتاج حسابًا جامعيًا أو صلاحية مقرر.

**إذا أعطاك الدكتور حزمة برنامج تتوافق مع نسخته وكتاب المقرر، استخدمها بعد التحقق من مصدرها وترخيصها، بدل الاعتماد على إصدار قديم لمجرد توفره للتنزيل.**

### 2. تثبيت Excel QM

1. تأكد من تثبيت **Excel Desktop** على Windows، وليس نسخة المتصفح فقط.
2. ادخل إلى مصادر Pearson الخاصة بالمقرر، وحدد **Excel QM / Excel OM-QM** المتوافق مع إصدار Excel المستخدم لديك.
3. نزّل ملف الإضافة أو المثبّت من المصدر المرخّص واتبع تعليماته.
4. افتح Excel وابحث عن تبويب **Excel QM** ضمن الشريط العلوي **Ribbon**. في بعض الإصدارات يمكن تشغيل Excel QM من اختصار يبدأ معه Excel.
5. إذا لم يظهر، افتح **File → Options → Add-ins**، ثم **Manage: Excel Add-ins → Go**؛ تحقق من أن الإضافة مفعّلة أو حدد ملفها الأصلي من **Browse**.
6. اختر نموذجًا من قوائم الإضافة وتأكد من أن Excel يُنشئ ورقة تحتوي على خلايا للمدخلات وصيغ أو نتائج.

### 3. تثبيت POM-QM / QM for Windows

يشرح **manual.pdf**، الفصل الأول (*Installing the Software*، صفحة PDF 14)، أن عملية التثبيت تبدأ بتنزيل الحزمة من موقع Pearson أو صفحة MyLab المرتبطة بالمقرر، ثم اتباع معالج الإعداد.

1. نزّل الحزمة المسموح باستخدامها من Pearson أو نظام المقرر.
2. أغلق البرامج المفتوحة وشغّل مثبت الحزمة بالطريقة الموثقة.
3. اتبع خطوات الإعداد وأدخل معلومات المستخدم المطلوبة حسب الترخيص.
4. بعد التثبيت افتح **POM-QM for Windows** من اختصار سطح المكتب أو قائمة Start.
5. ستظهر شاشة البداية، ثم النافذة الرئيسية. تحقق من رقم الإصدار من الشاشة أو قائمة البرنامج، لأنه قد يختلف عن نسخة الصور في المرجع.

**بخصوص ملف `QMstartup.exe` المرفق:** تعرفت عليه كملف Windows تنفيذي، لكن **لم أشغّله ولم أتحقق من توقيعه أو صلاحية رخصته**. لذلك لا أضعه في هذا المستودع العام ولا أتعامل معه باعتباره ملف تثبيت كاملًا مؤكّدًا.

## الجزء الثاني: التعرف على الواجهة وطريقة العمل

### 4. واجهة Excel QM

عندما تفتح التبويب **Excel QM** فإنك تختار الوحدة المرتبطة بنوع المسألة. بعدها ينشئ البرنامج ورقة Excel تحتوي على أماكن مخصصة للبيانات، مثل **Demand Rate** و**Ordering Cost** و**Holding Cost** في مسائل المخزون، مع خلايا للمخرجات.

في ملفات المادة ظهرت أمثلة حقيقية لإضافة Excel QM في المواضع التالية:

| الملف المرفق | الصفحات | ما تظهره الأمثلة |
| :--- | :---: | :--- |
| Decision Analysis — الجزء الأول | 42–43 | نتائج Excel QM وجداول صيغ اتخاذ القرار، Program 3.2A / 3.2B |
| Inventory Control — الجزء الثاني | 9–10 | بيانات ونتائج Production Order Quantity، Program 6.2A / 6.2B |
| Inventory Control — الجزء الثاني | 16–17 | نموذج خصومات الكمية، Program 6.3A / 6.3B |
| Inventory Control — الجزء الثاني | 32–33 | حساب مخزون الأمان، Program 6.4A / 6.4B |
| Waiting Lines — الفصل 12 | 28 و46 و52 و60 | نماذج Excel QM لطوابير الخدمة، بما فيها خادم واحد وعدة خوادم |

هذه المراجع من الملفات التي أرسلتها، وليست ادعاء بأن كل شريحة تمثل نافذة تثبيت. **للصور الحقيقية** ارجع إلى الصفحات المذكورة في ملفاتك أو إلى مواد [Pearson الرسمية للكتاب](https://www.pearson.com/en-us/subject-catalog/p/quantitative-analysis-for-management/P200000009863/9780137864966). لم أعد نشر صفحات الكتاب المحمية بحقوق النشر كصور داخل المستودع.

### 5. واجهة POM-QM / QM for Windows

البرنامج المستقل له مسار عمل مختلف عن Excel. بحسب **دليل POM-QM Version 5** الذي رفعته (الفصلان الأول والثاني، صفحات PDF 17–27)، ستتعامل مع هذه العناصر:

| العنصر | استخدامه |
| :--- | :--- |
| **Module Tree** | شجرة على يسار الواجهة لبدء مسألة في إحدى الوحدات |
| **Module** | قائمة بجميع الوحدات، ويمكن عرض وحدات QM فقط |
| **File → New / Open** | إنشاء مسألة جديدة أو فتح ملف محفوظ |
| **Problem Creation** | إدخال عنوان المسألة واختيار النموذج وعدد الصفوف أو البدائل |
| **Data Screen** | إدخال المعطيات في جدول يشبه Excel |
| **Solve** | حل المسألة بعد التأكد من صحة المدخلات |
| **Solution Screen** | قراءة النتائج والجداول والرسوم المتاحة |
| **File → Save as Excel File** | في كثير من النماذج يمكن نقل بيانات وحسابات المسألة إلى Excel؛ ليست كل الوحدات مدعومة بنفس الطريقة |

**التسلسل العملي:** اختر **Module** المناسب ← أنشئ **New Problem** ← أدخل البيانات ← اختر **Solve** ← اقرأ **Solution Screen** ← احفظ النتيجة عند الحاجة.

يمكنك الرجوع إلى **manual.pdf** الذي رفعته، خاصة الصور الواردة في الصفحات 17–27؛ فهي صور حقيقية من البرنامج الموثق، وليست رسومات أُنشئت لغرض الدليل.

## الجزء الثالث: ما الذي أستطيع استخدام البرنامج فيه؟

راجعت الفصول المرفقة وملف Excel الذي رفعته بعنوان **الاختبار النهائي.xlsx**. يحتوي الملف على أوراق تخص **Decision Tables** و**Waiting Lines** و**EOQ** و**POQ**. لم أنشر بيانات الملف أو إجابات الاختبار، واكتفيت بتحديد أنواع النماذج.

هذه أهم الاستخدامات المرتبطة مباشرةً بمحتوى المادة:

- **Decision Analysis:** مقارنة البدائل في ظروف التأكد والمخاطرة وعدم التأكد، باستخدام **Maximax وMaximin وEMV وEVPI** وجداول العوائد وأشجار القرار (الفصل 3).
- **Inventory Control:** تحديد **Economic Order Quantity (EOQ)** و**Production Order Quantity / EPQ**، ونقطة إعادة الطلب **ROP**، وخصومات الكمية ومخزون الأمان (الفصل 6).
- **Waiting Lines / Queuing:** دراسة معدل الوصول والخدمة، ونسبة انشغال الخادم، ومتوسط طول الطابور ووقت الانتظار، مع التمييز بين نماذج **Single Server** و**Multiple Servers** (الفصل 12).
- **Markov Analysis:** إدخال مصفوفة انتقال احتمالات الحالات، وحساب احتمالات الحالات المستقبلية أو المستقرة حسب النموذج (الفصل 14).

وتذكر قائمة وحدات **POM-QM for Windows 5** في دليل البرنامج أيضًا: **Forecasting، Linear Programming، Transportation، Assignment، Integer Programming، Goal Programming، Project Management (PERT/CPM)، Quality Control، Simulation، Statistics، Networks** وغيرها. هذه قدرات البرنامج بحسب الدليل، وليست جميعها موضوعات ضمن ملفات المقرر التي رفعتها.

**انتبه:** وجود وحدة في POM-QM for Windows لا يعني بالضرورة توفرها بالشكل نفسه داخل **Excel QM** أو في إصدار أقدم.

## الجزء الرابع: تطبيق مثال واحد — Economic Order Quantity

سنستخدم مثال **Sumco Pump Company** من ملفك **Chapter 6 Inventory Control Models (1 of 2)**، الصفحات **16–18**. اخترته لأنه يناسب موضوع المخزون الذي تكرر في أوراق Excel، ويمكن التأكد من ناتجه بسهولة.

### المطلوب

تريد الشركة معرفة عدد الوحدات الأنسب في كل طلبية لتقليل مجموع تكلفتَي الطلب والتخزين. المعطيات الموجودة في الشريحة هي:

| المدخل | الرمز | القيمة |
| :--- | :---: | ---: |
| الطلب السنوي | `D` | 1,000 وحدة |
| تكلفة إصدار الطلبية | `S` | 10 دولارات |
| تكلفة الاحتفاظ بالوحدة سنويًا | `H` | 0.50 دولار |

### الحل يدويًا للمقارنة

</div>

```text
EOQ = SQRT((2 × D × S) / H)
EOQ = SQRT((2 × 1000 × 10) / 0.50)
EOQ = 200 units

Annual orders = D / EOQ = 1000 / 200 = 5
Average inventory = EOQ / 2 = 100 units
Annual ordering cost = (1000 / 200) × 10 = $50
Annual holding cost = (200 / 2) × 0.50 = $50
Total relevant annual cost = $100
```

### كيف أطبق المثال في Excel QM؟

1. افتح Excel وشغّل تبويب **Excel QM**.
2. اختر وحدة **Inventory** ثم نموذج **Economic Order Quantity** إذا كان متوفرًا باسم مماثل في إصدارك.
3. أدخل `D = 1000` و`S = 10` و`H = 0.5`.
4. راجع الخلايا الناتجة في الورقة وقارنها بالنتائج السابقة.
5. يجب أن تكون **كمية الطلب الاقتصادية 200 وحدة** إذا أدخلت المدخلات في النموذج القياسي الصحيح.

### كيف أطبقه في QM for Windows؟

1. افتح **Module → Inventory** ثم اختر **Economic Order Quantity**.
2. أنشئ مسألة جديدة وأدخل **Demand rate = 1000**، و**Setup cost = 10**، و**Holding cost = 0.50**.
3. اختر **Solve** ثم اقرأ النتائج في **Solution Screen**.
4. طابق قيمة **Optimal order quantity = 200** وعدد الطلبيات السنوية **5** والتكلفة ذات الصلة **100 دولار**.

هذا المثال يفترض شروط **EOQ القياسي** الواردة في الفصل: الطلب معروف وثابت، ولا توجد خصومات كمية أو نقص مخزون، وتكلفة الاحتفاظ والطلب ثابتتان. **لا تضف سعر الوحدة ضمن الـ100 دولار**؛ فهذا مجموع تكلفتَي الطلب والاحتفاظ فقط، دون تكلفة شراء الوحدات.

## أخطاء شائعة قبل تسليم الحل

| المشكلة | ما الذي تفحصه؟ |
| :--- | :--- |
| لم يظهر تبويب Excel QM | تفعيل الإضافة من **File → Options → Add-ins** وتوافقها مع نسخة Excel |
| برنامج QM المستقل لا يظهر داخل Excel | هذا طبيعي؛ **POM-QM for Windows** برنامج منفصل عن إضافة Excel |
| لا تظهر نفس القوائم في الصور | تأكد من الإصدار: **POM-QM 4 أو 5** يختلف عن **Excel QM 5.3** |
| النتيجة تختلف عن الحل اليدوي | افحص نوع النموذج ووحدات الزمن وقيم `D` و`S` و`H` |
| ملف التثبيت من مصدر مجهول | لا تشغله قبل التحقق من المصدر والتوقيع والترخيص |
| ظهور `#VALUE!` في نموذج Excel | تحقق من أن المدخلات أرقام، وأن نسبة التخزين لم تُدخل على أنها نص غير قابل للحساب |
