<h1><strong>دليل تثبيت واستخدام IBM SPSS Statistics</strong></h1>

<p><strong>إعداد:</strong> Talal Alsultan &nbsp; | &nbsp; <strong>آخر تحديث:</strong> 26 أكتوبر 2026</p>

إذا كان لديك واجب إحصاء، أو بيانات استبانة، أو مشروع يحتاج إلى تحليل وصفي أو انحدار، فبرنامج **IBM SPSS Statistics** من الأدوات التي تساعدك على تنفيذ هذه التحليلات. سأشرح لك هنا كيف تختار النسخة المناسبة، وتثبتها، وتتعرف على واجهتها، ثم تنفذ مثالًا بسيطًا للتأكد من أنها تعمل.

## 1. قبل التحميل: ما الذي تحتاجه؟

أهم خطوة هي معرفة **نوع ترخيص SPSS** الذي ستستخدمه. بعض المستخدمين يحصلون عليه باشتراك أو تجربة رسمية من IBM، بينما قد توفر الجامعة ترخيصًا خاصًا وطريقة تفعيل مختلفة.

إذا كنت تستخدم ترخيص الجامعة، راجع تعليماتها أولًا حتى لا تثبت نسخة لا تتوافق معه. تتوفر معلومات التنزيل والخيارات على [صفحة IBM SPSS Statistics](https://www.ibm.com/products/spss-statistics).

| ما لديك | ما الذي تفعله؟ |
| :---: | :---: |
| اشتراك SPSS | سجّل الدخول بالحساب المرتبط بالاشتراك |
| نسخة تجريبية رسمية | اتبع التسجيل في صفحة التجربة وشروط مدتها |
| ترخيص جامعي أو تقليدي | استخدم النسخة ورمز التفعيل اللذين توفرهما الجهة المرخصة |

## 2. التحميل والتثبيت خطوة بخطوة

1. افتح [صفحة IBM SPSS Statistics](https://www.ibm.com/products/spss-statistics) وحدد خيار التجربة أو الاشتراك أو طريقة الترخيص المتاحة لك.
2. سجّل الدخول باستخدام **IBMid**، أو أنشئ حسابًا إذا طلب منك الموقع ذلك. استخدم بريد الجامعة عندما يكون الترخيص مرتبطًا به.
3. نزّل النسخة التي تتوافق مع جهازك، سواء كنت تستخدم Windows أو macOS.
4. بعد اكتمال التحميل افتح المثبّت الرسمي، واتبع تعليماته حتى تنتهي عملية التثبيت.
5. شغّل SPSS وأكمل التفعيل حسب نوع ترخيصك. بعض التراخيص تستخدم الحساب، بينما قد تتطلب التراخيص التقليدية **Authorization Code**.
6. عند فتح البرنامج، تأكد من ظهور نافذتي **Data View** و**Variable View**، ثم انتقل إلى التجربة في القسم الرابع.

**مهم:** رمز التفعيل لا يمكن استبداله برمز مأخوذ من شرح عشوائي على الإنترنت. إذا لم يعمل الترخيص، راجع IBM أو الجهة التي وفّرته لك.

## 3. تعرّف على واجهة SPSS

بعد فتح البرنامج ستجد أدوات متعددة. لا تحتاج إلى معرفة كل شيء في البداية؛ يكفي أن تبدأ بالأجزاء التالية:

| الجزء | استخدامه في التحليل |
| :---: | :---: |
| **Variable View** | تعريف اسم المتغير ونوعه ومستوى قياسه والقيم المفقودة |
| **Data View** | إدخال القيم؛ كل صف يمثل حالة أو سجلًا، وكل عمود يمثل متغيرًا |
| **Analyze** | تشغيل الإحصاء الوصفي والاختبارات والانحدار |
| **Graphs** | إنشاء الرسوم المناسبة للمتغيرات |
| **Transform** | حساب متغيرات جديدة أو تحويل القيم |
| **Data** | فرز السجلات ودمج الملفات وتعديل شكل البيانات |
| **Output Viewer** | قراءة جداول النتائج التي ينتجها البرنامج |

## 4. طبّق أول تحليل

سنجرب حساب المتوسط والانحراف المعياري لخمس درجات تدريبية: **70، 75، 80، 85، 90**.

1. في **Variable View** أنشئ متغيرًا باسم `Score`، واجعل `Type = Numeric` و`Measure = Scale`.
2. انتقل إلى **Data View** وأدخل الدرجات الخمس، كل درجة في صف مستقل.
3. من القائمة اختر **Analyze → Descriptive Statistics → Descriptives**.
4. انقل المتغير `Score` إلى مربع المتغيرات، ثم اضغط **OK**.
5. افتح نافذة **Output Viewer** لقراءة النتائج.

**Output (مثال محسوب من البيانات السابقة):**

```text
Variable       N       Mean       Std. Deviation
Score          5       80.00             7.906
```

<div dir="rtl" align="right">

المتوسط هو **80**، والانحراف المعياري العيني يقارب **7.906**. وقد يختلف شكل جدول SPSS قليلًا بحسب الإصدار. هذه مجرد بيانات تدريبية وليست نتائج دراسة فعلية.

بعد ذلك يمكنك تجربة الانحدار من **Analyze → Regression → Linear**، مع اختيار المتغير التابع في **Dependent** والمتغيرات المستقلة في **Independent(s)**. لا تعتمد على قيمة الدلالة فقط؛ افحص أيضًا صلاحية النموذج وافتراضاته ومعنى النتائج.

## 5. حلول المشكلات التي قد تواجهك

| المشكلة | الحل الذي تبدأ به |
| :---: | :---: |
| التثبيت توقف قبل الاكتمال | تحقق من صلاحيات الجهاز، ومن توافق نظام التشغيل مع النسخة |
| تظهر رسالة License أو Authorization | راجع نوع الترخيص، وحساب IBMid أو Authorization Code بحسب النسخة |
| لا يمكنك استيراد Excel | أغلق الملف في Excel، ثم استخدم **File → Open → Data** وتحقق من عناوين الأعمدة |
| الأرقام تظهر كنصوص | راجع **Type** و**Measure** في Variable View |
| نفذت التحليل ولم تظهر النتائج | ابحث عن نافذة **Output Viewer** من قائمة Window |
| انتهت فترة التجربة | استخدم اشتراكًا أو ترخيصًا جامعيًا صالحًا |
| الحروف العربية غير واضحة | افحص ترميز الملف وإعدادات الاستيراد قبل التحليل |

## 6. صيغ الملفات التي ستتعامل معها

| الامتداد | ماذا يحتوي؟ |
| :---: | :---: |
| `.sav` | بيانات SPSS وتعريفات المتغيرات |

| `.spv` | جداول النتائج في Output Viewer |
| `.csv` | بيانات نصية يمكن استيرادها إلى SPSS |
